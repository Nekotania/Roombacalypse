# Your sound files

Put your own sound files here, for example the collision sound:

```bash
python main.py --sound sounds/my-scream.wav
```

Everything in this folder except this README is ignored by git. Keep it
that way: clips from films, cartoons and games are copyrighted, so they
must not be committed to the repository or pushed to GitHub.

`--sound bonk` plays a sound the simulator synthesises itself, so it works
without any files.
